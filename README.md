# Pain Diary

A private pain log for iPhone: where it hurts, a 0–10 pain score, stiffness and fatigue timings, notes, a calendar and a report to show a health professional.

**Your entries never leave your phone.** They are stored on the device only. This repository contains just the app's code; it has no access to anyone's data.

## Install
1. Open the app's GitHub Pages link in Safari on your iPhone.
2. Tap Share, then **Add to Home Screen**.
3. Open it from the Home Screen icon (use that icon from now on, so your entries stay in one place).

## Backups
Use **Backup → Export backup** and save the file to Files or iCloud Drive. Keep it private: it contains your logs. **Restore from a backup file** adds entries back without deleting anything.
